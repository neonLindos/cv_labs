- По каждой работе студент должен показать минимум один неудачный случай и объяснить, почему метод дал ошибку.
- На защите студент должен уметь объяснить формулу, параметр алгоритма и участок собственного кода.

### Цель работы

Научиться представлять изображение как числовую матрицу/тензор и вычислять статистические характеристики пикселей вручную и программно.

### Почему это важно

Почти любой CV-метод начинается с численного представления данных. Статистика каналов помогает понять распределение цветов, а ковариация и Mahalanobis distance показывают взаимосвязь признаков и их относительный масштаб.

### Логика работы

```text
Изображение → матрица H×W×C → статистика каналов → covariance → расстояния → проверка в NumPy
```

### Минимум теории

```text
μ = (1/N) Σ x_i
σ² = (1/N) Σ (x_i − μ)²
Cov(X,Y) = (1/N) Σ (x_i−μ_x)(y_i−μ_y)
||A||_F = sqrt(Σ_i Σ_j a_ij²)
d_M(x,μ) = sqrt((x−μ)^T Σ^(-1)(x−μ))
```

Отклонения: −24, −18, −12, −6, 0, 6, 12, 18, 24.

```python
def entropy_u8(gray):

    p = hist / hist.sum()
    p = p[p > 0]
```

### Почему это важно

Вызов GaussianBlur скрывает два важных факта: фильтрация — линейный оператор, а Gaussian kernel сепарабелен. Это напрямую влияет на вычислительную стоимость и понимание частот.

### Логика работы

```text
kernel → ручная корреляция → separable decomposition → собственный filter → timing → FFT
```

### Минимум теории

```text
Y[i,j] = Σ_m Σ_n I[i+m,j+n]K[m,n]
K = a b^T  для rank(K)=1
H(ω) = Σ_n h[n] e^(−jωn)
```

```python
def correlate2d(gray, K):
    kh, kw = K.shape
    ph, pw = kh//2, kw//2
    x = np.pad(gray, ((ph,ph),(pw,pw)), mode='reflect').astype(float)
    out = np.zeros_like(gray, dtype=float)
    for i in range(gray.shape[0]):
        for j in range(gray.shape[1]):
            roi = x[i:i+kh, j:j+kw]
            out[i,j] = np.sum(roi * K)
    return out
```

### Почему это важно

### Логика работы

### Минимум теории

```text
M = Σ w [[I_x², I_x I_y],[I_x I_y, I_y²]]
R = det(M) − k·trace(M)²
```

```python
    pred = pred.astype(bool); gt = gt.astype(bool)
    tp = np.logical_and(pred, gt).sum()
    fp = np.logical_and(pred, ~gt).sum()
    fn = np.logical_and(~pred, gt).sum()
    tn = np.logical_and(~pred, ~gt).sum()
    iou = tp / (tp + fp + fn + 1e-12)
    dice = 2*tp / (2*tp + fp + fn + 1e-12)
    precision = tp / (tp + fp + 1e-12)
    recall = tp / (tp + fn + 1e-12)
    return tp, fp, fn, tn, iou, dice, precision, recall
```

```python
def iou_xyxy(a, b):
    x1 = max(a[0], b[0]); y1 = max(a[1], b[1])
    x2 = min(a[2], b[2]); y2 = min(a[3], b[3])
    inter = max(0.0, x2-x1) * max(0.0, y2-y1)
    aa = max(0.0, a[2]-a[0]) * max(0.0, a[3]-a[1])
    bb = max(0.0, b[2]-b[0]) * max(0.0, b[3]-b[1])
    return inter / (aa + bb - inter + 1e-12)
```

### Почему это важно

### Логика работы

```text

```

### Минимум теории

```text
BCE = −[y ln p + (1−y) ln(1−p)]
SoftDice = (2Σp_i y_i + ε)/(Σp_i + Σy_i + ε)
∂L_BCE/∂z = p−y,   p=sigmoid(z)
```
